# OnderzoeksopdrachtDemos
In de eerste demo worden tokens aangemaakt die aantonen hoe dat qr-codes maar en keer gescand kunnen worden en hoe dat tijdsgebonde codes alleen maar binnen een tijdslot gescand kunnen worden.

In de 2de demo wordt getoond hoe gescande QR-codes lokaal worden opgeslagen wanneer er geen verbinding is, en hoe deze gegevens op een later moment gesynchroniseerd worden met de backend zodra er weer verbinding beschikbaar is.
